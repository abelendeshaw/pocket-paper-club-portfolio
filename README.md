# Pocket Paper Club — Tiny Treats Mystery Club

A responsive, static portfolio website for the Cozy Bakery printable papercraft collection.

## Deploy

Import this GitHub repository into Netlify at https://app.netlify.com/start, choose **Deploy from GitHub**, use the default branch `main`, leave the build command empty, and set the publish directory to `.`.

## Contents
- `index.html` — complete static website, all CSS inline; no framework or build step.
- `.gitignore` — excludes Netlify local state.

Note: Illustrated bakery emoji are used as visual stand-ins for printable artwork. Physical papercraft assembly is not claimed as verified.
